## 💻 Tech Stack & Architecture

- **Framework**: [Astro](https://astro.build/) (Static Site Generation) + [Tailwind CSS](https://tailwindcss.com/) + [React](https://react.dev/)
- **Design Philosophy**: Minimalist Academic Editorial, Julian Perilla 100vh Single-Screen Fluid Geometry
- **Interactive Visuals**:
  - Geodetic Harmonic Wave Engine (HTML5 Canvas)
  - 3D Interactive WebGL / Canvas Elements (Game Boy & Literature Flipbook)
- **Typography**: Josefin Sans (Name Heading) & Montserrat (Body & Nav)
- **Deployment**: GitHub Pages via GitHub Actions CI/CD

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview

# Run type check and regression tests
npm run check
npm test
```
