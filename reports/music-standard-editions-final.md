# 音乐整理最终结果

核验日期：2026-09-08。本报告记录本次发布的音乐数据；部署状态以 GitHub Actions 为准。

最终：**92 位歌手，306 张唱片，552 首歌曲**。其中录音室专辑 270 张、EP 8 张、单曲 28 张。

原始资料共 965 首；本次展示 552 首，其余 413 首不展示。原始导入资料保留，Apple Music 资料库没有改动。

相较本轮开始的 247 位歌手 / 430 张唱片 / 656 首歌，本轮通过联网证据补回 54 首；另有 158 首因歌手门槛或发行版本规则退出展示。

## 应用标准

- 标准录音室专辑优先；同一作品只展示一个原版专辑，不另列豪华版、纪念版或重制版。
- 仅在没有标准录音室专辑归属时保留真实发行的单曲 / EP；不把精选集、原声带或 mixtape 改名成专辑。
- Taylor Swift 按已确认的原版政策；重录版独有曲目不展示。
- 对同一录音的 remaster 可归回原版曲目表；不把重录、remix、电影剪辑版当原录音搬移。
- 发行筛选之后，每位歌手至少两首不同的合格歌曲，可以来自同一张专辑。
